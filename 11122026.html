Executive summary

1

An active ScreenConnect campaign is hitting MSPs — and N-able’s N-central is still burning. Attackers used compromised cloud-hosted ScreenConnect instances’ own “Run Command” feature from 01:48 SGT today to push a rogue client and a PowerShell toolkit onto every reachable host; Huntress is tracking 6 compromised MSPs, 286+ endpoints across 47 organisations, and the toolkit traps any technician who connects to an infected host. ConnectWise points, unvalidated, at third-party extensions. Separately, N-able completed its hosted N-central upgrade at 09:04 SGT yesterday after the 9 November public release of 33 alleged zero-days with PoC code (“Able2Shell”); scanning tied to the published PoCs is now observed, though no customer-server compromise is confirmed. Both tools are the remote-access layer MSPs use to manage small banks — treat both as patch-and-hunt priorities today.

2

Japan’s SMBC group disclosed a third breach in a week, and Korea’s sector assessor breach grew clearer. SMBC Nikko Securities confirmed unauthorised access to its employee stockholding-association administration system, with personal data of up to 56,487 members leaked or possibly leaked — names, addresses, holdings and transfer-destination account details. In Korea, the Financial Security Institute breach is now scoped at about 130 files from 48 mutual-finance firms (about 850 records), entered by a fake account impersonating a Financial Supervisory Service official; the reported attacker IP count conflicts across outlets (more than 100, 236, about 246 — all said to be domestic Korean), and an FSI official’s suggestion that AI was “likely” used is an estimate, not confirmed. No new KEV additions were made on 11 November.

3

Node.js shipped its security releases, Apache fixed a critical mod_http2 RCE, and Fortinet published two more critical FortiMail flaws. Node.js 26.13.1 / 24.22.3 / 22.23.5 fix 16 CVEs, seven High — worst is CVE-2026-123864, an HTTPS heap-memory disclosure that can expose TLS private keys and other users’ requests; no exploitation or public PoC reported, and Node.js published no CVSS scores. Apache 2.4.71 fixes CVE-2026-119618, a critical mod_http2 race condition leading to remote code execution (2.4.55–2.4.70). Fortinet’s two new FortiMail criticals (CVE-2026-126263, 9.8 SQL injection; CVE-2026-126155, 9.1 unauthenticated IBE webmail session hijack) were both found with the help of an AI model — the same week Microsoft’s FORGE Lab showed AI-assisted scanning producing 33 kernel CVEs. Unit 42 published the week’s clearest ARTEX picture: 1,323 internet-facing CyberStrikeAI hosts and 609 ARTEX hosts, with a behavioural hallmark table defenders can hunt on; and Arctic Wolf reported AntiFox, an ARTEX fork, being used to steal AWS credentials. A 9 November Datadog report, missed by earlier editions, shows ARTEX hunting financial data inside AWS environments in October.

AI in the current threat landscape

AI as a target, AI as a weapon or accelerator, and AI as a risk and control problem for BFSI.

AI as a target

Notion transcripts exposed via Fireworks (NEW, reported 12 Nov 04:54 SGT). Notion says the Fireworks AI breach exposed Notion AI chat transcripts in fewer than 1% of workspaces, from the dataset used for its Insights feature. Fireworks had contractually committed to zero data retention for Notion data; data was in fact retained. Notion advises affected users to rotate any passwords, API keys or credentials pasted into Notion AI. Standing: Railway’s final incident report (primary 10 Nov; secondary reporting 11 Nov) — ~$740,000 in unauthorised AI usage on stolen keys, environment variables from up to 100,000 workspaces (upper bound), linked-account tokens for 1,852 users exposed and reset. Google/Mandiant LLMjacking research (2–3 Nov) — stolen cloud credentials and LLM API keys, fraudulent bills over $100,000 in a single day and up to ~$1m cumulative at some victims, financial services among victims. Google’s 2027 security forecast (summary 11 Nov) names LLMJacking as the monetisation pattern and says attackers are going after proprietary model weights, custom agent skills, prompt libraries and cloud GPU compute — vendor forecast, not findings. Standing controls: key inventory and rotation, endpoint exposure, spend and invocation monitoring with revoke-and-rotate.

AI as a weapon / accelerator

Unit 42 ARTEX post and AntiFox (NEW, 11 Nov). Unit 42 (11 Nov): as of October 2026, 1,323 internet-facing hosts running CyberStrikeAI and 609 running ARTEX (21 running both); 14 tools analysed across four categories (recon: ARL, Scope Sentry, Nemo, XingRin, OpenEASD; agent-led testing: CyberStrikeAI, ARTEX, Cairn, PentAGI, AutoHunter; code audit: DeepAudit, AIxVuln; AI-system assessment: AI-Infra-Guard). ARTEX’s author has made the repo closed-source and ceased public development after scrutiny; alternatives are filling the void. Unit 42 IR investigated multiple intrusions where the attacker’s server hosted an ARTEX console; Managed Threat Hunting tracked a coordinated ARTEX campaign against customer cloud environments (retail, consulting, others). Observed intrusions used no software vulnerability — they abused password-reset pages and exposed APIs to reach cloud access, sometimes in under a day. Behavioural hallmarks in the TTP Tracker; hunt back to September 2026. AntiFox (Arctic Wolf, 10 Nov; reported 11 Nov): an ARTEX 0.1.1 fork, Chinese-language agentic pentest platform (~474–482 stars, ~251–252 forks, now v2.0), used to steal AWS credentials — webshell to config secrets to Secrets Manager. Datadog Security Labs (9 Nov; catch-up, missed by earlier editions): in-the-wild ARTEX activity inside AWS environments in October 2026, focused on financial data — entry via compromised long-term IAM keys and abuse of public Cognito user pools; with a valid key, ARTEX’s most frequent action was CloudWatch FilterLogEvents (every call limit 1000) searching for crypto companies, hedge funds and financial institutions; hundreds of additional internet-exposed ARTEX consoles found in early November, often in Mandarin and hosted in Singapore and Hong Kong; rebranded consoles ScopeWeaver, LUCK, Guanlan SEC. No named victims and no confirmed exfiltration stated. Check Point’s October 2026 threat landscape (11 Nov): ransomware hit a record 1,063 reported attacks in October (+35% vs Oct 2025), and new extortion group “n0n” entered the top 3 within a month of starting operations, “relying heavily on AI-assisted tooling” — vendor telemetry, and the AI-tooling claim is Check Point’s characterisation, not independently verified. No new AI-scaled phishing, vishing or deepfake incident was disclosed in-window. The $129m AI voice-clone indictment reported in-window was unsealed 5 Nov — fraud-pattern warning, not new.

AI as a risk and control problem for BFSI

OCC examiner framework; UK deepfake survey; AI finding vulnerabilities faster than humans can review them. OCC Bulletin 2026-54 (released 4 Nov; PYMNTS analysis 11 Nov): a framework guiding examiners reviewing banks’ generative and agentic AI use — six pillars / sixteen components; consequence-based classification (autonomous payment agent = Tier 1, internal productivity tool = Tier 4); it creates no new rules and sets no supervisory expectations — examiners assess AI through existing risk categories (fraud, privacy, cybersecurity, third-party). In-window item is the 11 Nov analysis, not a new regulatory action. Digidentity survey (SC Media, 11 Nov): 69% of UK banking customers doubt their bank can detect AI deepfake impersonation; 80% expect banks to use advanced deepfake detection in selfie-based identity verification; 53% say SMS one-time codes are no longer sufficient. Survey data, not an incident — report as such. AI-assisted vulnerability discovery is now a standing fact on both sides: Fortinet’s two new FortiMail criticals were found with the Frontier AI model Claude Mythos, and Microsoft’s FORGE Lab (11 Nov) reports AI-assisted scanning (MDASH; Sonnet 4.6/GPT-5.x) produced 26,502 raw findings → 621 PoC-backed cases → 59 public upstream kernel reports, 33 assigned CVEs (24 High or above), eight confirmed working local root privilege-escalation exploits in lab conditions (including CVE-2026-64563, rhashtable use-after-free, exploitable by unprivileged users via netlink socket diagnostics); fixes merged for 38 of 59 reports; average bug age 8.1 years (oldest, CVE-2026-74544, ≥21 years). Standing: NCSC UK chief executive’s 9 Nov warning of an AI-powered ransomware attack on UK critical national infrastructure being “highly likely” by 2028 is a forecast/assessment, not a new incident. Standing controls: CSA/GovTech/IMDA personal-AI-agent advisory (6 Nov) — do not give agents access to banking, government or healthcare accounts; Sophos malicious AI-agent “skills” research (6 Nov); Haiou “prompt adware” (Check Point, 4 Nov); Elastic’s finding that attackers execute commands through Claude Code and ChatGPT desktop in confirmed intrusions. Also in-window: npm replaced all 122 versions of @apexacc/cli (1.1.8–1.6.2) with a 0.0.1-security placeholder at 06:36 SGT 11 Nov (GHSA-pg98-9cmp-wcf5) — Elastic Security Labs tracks REF8801: npm packages that rerouted AI-agent traffic (prompts, file reads, tool results) through the operator’s API and dropped CloudSyncD (macOS backdoor) and a Telegram stealer; @apexfdn/copilot-mcp (0.1.0–0.11.6) still published and relays server-supplied shell commands to the AI client — treat as attacker infrastructure. Supply-chain risk in AI coding-agent tooling: developers installing these packages expose prompts, code and credentials.
